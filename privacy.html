On Mic Daily: privacy policy

Last updated: November 1, 2026.

On Mic Daily is a personal project that posts short video clips to its own social media channels. Its software is used only by the project's owner. It is not offered to the public, and nobody else can sign in to it.

What it accesses

With the owner's authorization, the software uses the YouTube API Services to upload videos to the owner's own YouTube channel and to read that channel's public details, video statistics and audience statistics. It does not access any other person's Google account or data.

How the data is used and stored

Channel and video statistics are used to measure how the clips perform, and totals and per-video numbers appear on the project's public statistics page. The login token is stored privately on the owner's computer and in private project settings. Nothing is sold, shared for advertising or used to train AI models.

Google and YouTube

This project uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be removed at any time at Google's security settings page.

Contact

Questions can be sent through this project's GitHub page.
